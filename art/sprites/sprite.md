# Sprites

- **Size:** transparent PNG, at most 64 x 128 px.
- **Files:** `art/sprites/<name>.png`. For animation frames, use `<name>_1.png`, `<name>_2.png`, and so on.
- **Colors:** only the team palette. **Hand-made only:** fictional rockets, no real brands or logos.
