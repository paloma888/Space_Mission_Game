# Music

- **Made with BeepBox** (free, in the browser). Export as `.mp3`.
- **Files:** `audio/music/<name>.mp3`. Play it with `ui.music('<name>')`.
- **Under 500KB each.** Keep loops to about 30 to 60 seconds.

Planned tracks (RULEBOOK section 9):

| File | What it is | When it plays |
| --- | --- | --- |
| `build_calm.mp3` | Calm loop | Hiring, build and trail |
| `launchweek_tense.mp3` | Tense loop | Launch week |
| `fanfare_orbit.mp3` | Short victory fanfare | `orbit` ending |
| `fanfare_aliens.mp3` | Silly, bouncy fanfare | Secret `aliens` ending |
| `sting_abort.mp3` | Relieved, "close call" sting | `abort` ending |
| `sting_bankrupt.mp3` | Sad-trombone style sting | `bankrupt` ending |
| `sting_window.mp3` | Clock-running-out sting | `window_closed` ending |
| `memorial.mp3` | Slow, quiet and respectful, no fanfare | `lost` ending |
